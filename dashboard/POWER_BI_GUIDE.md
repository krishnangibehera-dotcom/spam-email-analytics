# Power BI Dashboard Guide

Import `../outputs/spam_email_powerbi_data.csv` into Power BI.

Suggested visuals:
- Total Messages (Card)
- Spam Messages (Card)
- Spam Percentage (Card)
- Ham vs Spam (Column chart)
- Message Length by Category
- Average Word Count by Category
- Prediction Label breakdown
- Detail table containing Message, Category and Prediction Label

Suggested slicers:
- Category
- Prediction_Label
